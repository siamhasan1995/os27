# OS27 Launcher (Redmi 13 / HyperOS)

Build the APK with no local setup:
1. Create a new GitHub repo, upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab -> "Build APK" -> wait ~4 min.
3. Download the `OS27Launcher-apk` artifact, unzip, install `app-debug.apk` on the phone.

Or open in Android Studio (Koala+) and press Run.

After installing:
- Press Home -> choose "OS27 Launcher" -> Always.
- Settings -> Accessibility -> Installed apps -> "OS27 Full-Screen Gestures" -> turn on
  (HyperOS may also need: Settings -> Apps -> OS27 Launcher -> Autostart + "No restrictions" battery).
